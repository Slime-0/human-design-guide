# 人間工学・情報デザイン 学習ガイド

人間工学・情報デザインを、読む・試す・確認することで学ぶ静的Web教材です。

公開URL：<https://slime-0.github.io/human-design-guide/>

## 内容と機能

- [簡易版](index.html)：8つのテーマ、検索・用途別絞り込み、4つの体験、16問のクイズと復習、チェックリスト、記入メモ、印刷、ダーク表示。
- [詳細版](人間工学・情報デザイン_重複統合版.html)：詳しい解説、一次資料へのリンク、検証記録。簡易版の根拠リンクから該当箇所へ移動できます。

数値の条件や学習内容の確認状況は、各ページの記載を参照してください。「未確認」などの表示は、確認済みであることを意味しません。

## 保存と引き継ぎ

クイズの回答、チェック状態、確認記録、下書きメモ、表示設定は、利用中のブラウザー内の `localStorage` に保存します。端末・ブラウザー間では自動同期しません。ブラウザーのサイトデータを削除すると、保存内容も消去されます。

ローカルHTMLから公開サイトへ移った場合も、既存データは自動移行されません。クイズの回答と学習位置は、元の教材の「バックアップを保存」でJSONを書き出し、公開サイト側で読み込んで復元できます。このJSONにチェック状態・確認記録・下書きメモは含まれません。必要な内容は元の教材からコピーまたは印刷して保管してください。

## 公開・更新手順

1. `main` ブランチのルートに、`index.html`、`人間工学・情報デザイン_重複統合版.html`、`.nojekyll` を配置します。
2. GitHubの **Settings → Pages** で、公開元を **Deploy from a branch**、ブランチを **main**、フォルダーを **/(root)** に設定します。
3. 更新時は対象のHTMLを同じ場所へコミットします。詳細版のファイル名を変更する場合は、簡易版からのリンクも合わせて更新してください。
4. デプロイ完了後、公開URLで表示・操作・詳細版へのリンクを確認します。

CSSとJavaScriptはHTML内に含まれ、ビルド処理や外部ライブラリーのインストールは不要です。`.nojekyll` はJekyllによる処理を使わず静的ファイルを公開するために残してください。
